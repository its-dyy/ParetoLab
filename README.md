# ParetoLab

**多目标优化分析与可视化平台**

*Interactive Multi-Objective Analysis and Visualization*

> 面向多目标决策与实验评估，围绕 Pareto 非支配分析、多维交互式可视化和偏好辅助决策，帮助用户识别候选方案之间的权衡关系，开展系统化比较。

## 什么是 Pareto（帕累托）？

“Pareto”源自意大利经济学家维尔弗雷多·帕累托（Vilfredo Pareto）的名字。在多目标优化中，**Pareto 最优**描述的是一种无法在不牺牲其他目标的前提下继续改善某个目标的状态：如果不存在另一个方案在所有评价目标上都不差、并且至少在一个目标上更优，那么该方案就是**非支配解**。

例如，在同时追求**更高的模型准确率**和**更低的推理时延**时，一个准确率较高但运行较慢的模型，与一个准确率略低但运行更快的模型，可能各有优势，无法简单判定哪一个“全面更好”。相反，如果某个模型的准确率更低、推理还更慢，就可能被其他模型支配。由多个非支配方案构成的集合称为 **Pareto 非支配解集**；这些方案在目标空间中的表现构成相应的 **Pareto 前沿**。

对有限的实验或业务数据而言，得到的是**当前样本中的经验 Pareto 前沿**，不能直接等同于优化问题的全局最优前沿。本项目命名为 **ParetoLab**，意在提供一个围绕 Pareto 关系开展数据探索、方案比较和辅助决策的开放式分析平台。这里的 Pareto 概念指多目标优化中的非支配关系，而非通常所说的“二八法则”。

## 项目简介

在科研实验、工程设计与实际决策中，候选方案通常需要同时满足多个评价目标。例如，机器学习模型希望提高预测精度，同时降低推理时延和资源开销；工程方案则可能需要兼顾性能、成本、重量与可靠性。由于不同目标之间存在相互制约，单纯按照某一指标排序，或直接将多个指标合成为一个分数，可能掩盖有价值的折中方案，难以全面描述候选方案之间的相对优劣。

**ParetoLab** 计划开发一个模块化、交互式的多目标分析平台，面向已经获得评价结果的候选方案数据，构建从数据整理、目标配置、非支配分析到结果展示与辅助决策的完整分析流程。用户可导入 CSV 或 Excel 数据，自主选择评价指标，分别设置最大化或最小化方向；系统则基于 Pareto 支配关系识别经验非支配解，并通过**多层非支配排序**对不同候选方案进行分层，帮助用户了解哪些方案具有竞争力，以及其他方案与前沿之间的相对关系。

在此基础上，项目计划结合二维、三维散点图和平行坐标图展示多目标数据分布、非支配层级与样本属性，并提供指标区间筛选、候选方案对比和偏好配置等交互操作。用户不仅能够观察不同目标之间的冲突与权衡，还能在特定约束或决策偏好下比较候选方案，最终导出分析结果，用于实验复核、方案评审和后续研究。

ParetoLab 的核心定位是**针对已有候选方案的多目标分析与决策支持**，而非直接搜索或生成新解的优化求解器。项目将重点关注非支配计算的正确性、多维分析的可解释性、交互体验，以及开源软件的可复现性和扩展能力。

## 核心功能规划

| 模块 | 计划实现的功能 |
| --- | --- |
| 数据导入与管理 | CSV / Excel 导入、数据预览、缺失值和重复值检查、数值指标选择与基础预处理 |
| Pareto 分析引擎 | 最大化 / 最小化混合配置、支配关系判定、非支配解识别与多层非支配排序 |
| 多维交互式可视化 | 二维 / 三维散点图、平行坐标图、层级高亮、区间筛选与样本详情查看 |
| 偏好辅助决策 | 指标偏好配置、约束条件筛选、候选方案对比及偏好变化分析 |
| 结果导出 | 非支配分析数据、候选方案对比结果及可视化图表导出 |

## 应用场景

- **科研实验与模型评估：** 综合分析准确率、推理时延、内存占用等指标，比较不同模型或实验配置的性能与资源开销。
- **工程设计与方案评审：** 在成本、性能、重量、可靠性等目标之间识别非支配设计，辅助比较不同约束下的候选方案。
- **运营管理与资源配置：** 对已有调度、配置或服务方案的时间、成本、资源消耗和服务水平进行多目标评估与偏好分析。

上述场景均以已有候选方案的评价数据为输入。初期将使用模拟数据和合规的公开示例数据进行验证。
